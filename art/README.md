# App icon

One design for both platforms: three white peers joined in a triangle on blue `#1A5FD0`.

| File | Use |
| --- | --- |
| `icon-1024.png` | iOS `AppIcon` (1024 × 1024, no transparency) |
| `icon-play-512.png` | Play store listing icon |

The Android adaptive icon (`android/demo/src/main/res/drawable/ic_launcher_foreground.xml`) draws the same shapes on a 108 × 108 viewport, at 108/1024 of the PNG's coordinates: peers at (54, 31.6), (34, 69.6) and (74, 69.6), radius 8.2, lines 4.6 wide.
